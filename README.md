# Оно тебе надо — Аукцион вещей, в которые никто не верил

Веб-сайт для аукциона необычных вещей, которые изначально не были признаны обществом, но стали культовыми в современной культуре.

## Особенности дизайна

- **Адаптивная верстка** с использованием CSS Grid и Flexbox
- **Плавная прокрутка** к разделам страницы
- **Интерактивные элементы** с hover-эффектами

## Функциональность

### Основные разделы:
1. **Шапка сайта** - навигация, логотип и контактная информация
2. **Главный баннер**
3. **Лоты** - карточки с товарами аукциона (фильмы, книги, картины)
4. **О проекте** - информация об аукционе
5. **Подвал** - контакты, навигация, социальные сети

## Стек

- **HTML5** - семантическая разметка
- **CSS3** - Grid, Flexbox 

## Адаптивность

Сайт оптимизирован для просмотра на различных устройствах с минимальной шириной 1100px.



*Проект создан в рамках курса "Фронтент-разработчик" от Яндекс.Практикума.
